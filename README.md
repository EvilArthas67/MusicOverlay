# MusicOverlay

Простой музыкальный оверлей для Windows.

Показывает:

* 🎵 Название песни и исполнителя
* 🖼️ Обложку
* ▶️ Play / Pause
* ⏮️ Предыдущий трек
* ⏭️ Следующий трек
* 🎚️ Ползунок и время трека

Оверлей появляется при взаимодействии с музыкой и автоматически скрывается через несколько секунд.

Сделано на **C# / WPF / .NET 10**.
