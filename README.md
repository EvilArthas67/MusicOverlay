# MusicOverlay

Простой музыкальный оверлей для Windows 11.

Показывает обложку, название трека, исполнителя и прогресс воспроизведения.

## Скачать

👉 **[Скачать MusicOverlay](https://github.com/EvilArthas67/MusicOverlay/releases/latest)**

Скачайте последнюю версию, распакуйте архив и запустите `MusicOverlay.exe`.

## Возможности

* Обложка и информация о треке
* Play / Pause
* Переключение треков
* Перемотка
* Системные мультимедийные клавиши
* Windows 11
